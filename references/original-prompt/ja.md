# XXD Panel 098｜原文プロンプト（日本語閲覧訳）

アップロード写真を一枚ずつ独立した上質なポスターにし、写真同士は結合しません。3:4縦構図、上下領域は高さ1:1です。上部は元写真の主体・構造・姿勢・実在感・自然光・色の空気を守り、軽い編集調整と自然な環境拡張だけを許可します。

下部は主体、輪郭、姿勢、物語関係を抽出し、faux-naïf picture-book illustration として再構成します。細いゆるい墨線、平面的な水彩／ガッシュ、見える筆跡、記号化、symbolic scale、naïve perspective、decorative narrative composition、大きな余白、意図的な不完全さを用います。主体は識別可能に保ち、歪んだ輪郭や探り線、むら塗り、遊びのある手描き文字を許容します。色は写真由来の明るく生命的な色を使い、淡い紙色に呼吸させます。文字は主題と暗喩から少量だけ自然に生やし、固定タイトル・番号・場所・言語・テンプレートを設けません。写実、厳密な遠近、滑らかなベクター、3D、商業カートゥーン、濁った色、背景の詰め込みを避けます。

> 閲覧用の忠実な訳です。実行時の創作権威は `zh-CN.md` です。
