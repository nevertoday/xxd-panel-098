# XXD Panel 098｜原文プロンプト（日本語閲覧訳）

アップロードした各写真を、それぞれ独立した上質なデザインポスターにしてください。複数画像を結合せず、写真ごとに個別出力します。全体は3:4の縦構図とし、上下二つの領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在する質感、自然な光と影、元の色彩の空気を保ちます。調整は軽い上質なカラーグレーディングだけにとどめ、アート雑誌、独立出版物、展覧会写真のような質感にします。画幅に合わせて周囲の環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別しやすい**主体、輪郭、姿勢、物語上の関係**を抽出し、**faux-naïf picture-book illustration** として再構成します。素朴派の水彩挿絵、ゆるい墨線、記号化した造形、手描き文字によって元画面の中心主題を語り直します。写真全体を描き写さず、複雑な細部を積極的に省き、人物、動物、建築、植物、器物、風景を、単純でありながら識別できる視覚記号へ変換します。元の対象が一目で分かりながら、天真さ、ユーモア、意識的なデザインを備えた物語性を持たせます。

造形には**細くゆるい黒または濃色の墨線＋平面的な水彩／ガッシュ風の色面**を使います。輪郭は少し歪み、比率はやや不器用で、遠近には主観性があって構いません。探り線、軽い反復、完全には閉じない輪郭も残せます。色は輪郭の中を完全に埋める必要はなく、筆跡、はみ出し、紙の白、むらのある被覆を保ちます。物語上の必要に応じて大小関係を適度に誇張し、厳密な写実比率の代わりに symbolic scale と naïve perspective を使えますが、主体の同一性と重要な姿勢は正確に保ちます。

構図は無造作な子どもの絵ではなく、設計された **decorative narrative composition** にします。元写真の最も重要な一つの物語中心を軸に形を再配置し、大小のずれ、取り囲み、上下の重なり、部分的な裁ち落とし、記号の反復、大きな余白によってリズムをつくります。現実では離れている要素を想像力のある小世界へ再編しても構いませんが、画面を埋め尽くしてはいけません。複雑な背景は積極的に捨て、環境の意味と感情を保つために最も有効な少数の記号だけを残し、童心と成熟した平面構成を両立させます。

上の写真から**最も明るく、鮮やかで、生命力のある色**を抽出して再調整します。平均的に色を拾ったり、意図的に灰色へ沈めたりしません。元画像の中心色を、軽やかで澄んだ平面水彩の色面へ変換します。空色、水青、若草色、レモンイエロー、暖かなオレンジ、コーラルピンク、ローズ、柔らかな紫などの明るい综合色を自然に形成し、大胆でありながら穏やかな寒暖の併置によって、楽しく癒やされる視覚リズムをつくります。明るい暖白、または元画像の総合的な色温度から導いたごく淡い紙色を広く残し、呼吸する空間にします。鮮やかでも刺激的にせず、豊かでも雑然とさせません。灰色に濁った色、暗い褐色、沈んだモランディ調、蛍光色、安価なキャンディ感は避けます。

文字は絵の一部として自由に現れ、固定の題名、番号、年、場所、言語をあらかじめ設定しません。主体、動作、感情、音、記憶、画面の比喩から、少数の語、短い文、数字、詩的断片を生成します。**細く稚拙で、筆圧の変化と不規則な字間を少し持つ手描き文字を使い、自然な傾き、揺れるベースライン、筆書きの痕跡を残します。** 文字の大きさを変え、少し回転させ、主体の縁や余白に沿って自由に育て、挿絵と交差し、取り囲み、呼応させても構いません。図と文字は同時に紙へ描かれたように感じさせ、後から見出しを載せたようにしてはいけません。

全体は、**loose ink linework、flat watercolor washes、visible brush marks、symbolic simplification、playful hand lettering、deliberate imperfection** が一体となった擬素朴派の絵本美学にします。明るく、優しく、ユーモラスで、天真で、力が抜け、生活感がありながら、常に成熟した構図意識と図形的な物語性を保ちます。写実的な挿絵、厳密な遠近法、精密な解剖、滑らかなベクター、デジタルグラデーション、3Dレンダリング、商業カートゥーン、背景の埋め尽くし、テンプレート化した子ども向けポスター感は避けます。
